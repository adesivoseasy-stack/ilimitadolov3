GitHub Token, repositório e branch para aplicar alterações
▼
Formato: dono/nome-do-repo — ex: joao/meu-projeto
📖 Passo a passo: Token GitHub (Clássico)
  1. Abra github.com/settings/tokens
  2. Clique em "Generate new token" → "Generate new token (classic)"
  3. Em "Note", digite um nome (ex: Bubbly Extension)
  4. Em "Expiration", escolha 90 days ou No expiration
  5. Em "Select scopes", marque ✅ repo (primeira opção — acesso completo)
  6. Role até o final e clique em "Generate token"
  7. 🔴 COPIE O TOKEN IMEDIATAMENTE! Ele começa com ghp_ e só aparece uma vez
  8. Cole aqui no campo "Token (PAT)" acima
⚠️ IMPORTANTE: Se você fechar a página sem copiar, terá que gerar um novo token. Guarde também em um lugar seguro (bloco de notas, gerenciador de senhas).
📋 Como pegar o nome do repositório
  1. No Lovable, abra seu projeto
  2. Clique no nome do projeto (canto superior esquerdo)
  3. Vá em "Settings" → "GitHub"
  4. Copie o nome que aparece no formato seu-usuario/nome-do-repo
  5. Se não estiver conectado, clique em "Connect project" primeiro
💡 Dica: Você também pode copiar direto da URL do GitHub. Ex: se a URL é github.com/joao/meu-app, o repositório é joao/meu-app
🔧 Erros comuns e soluções
Erro 401 — Token inválido: Seu token expirou ou foi digitado errado. Gere um novo em github.com/settings/tokens.

Erro 403 — Sem permissão: Seu token não tem o scope "repo" marcado. Gere um novo token e marque a opção "repo".

Erro 404 — Repo não encontrado: O nome do repositório está errado. Verifique: deve ser dono/repo (ex: joao/meu-app), não só o nome do repo.

"Repo não detectado": A detecção automática pode falhar. Cole manualmente o nome owner/repo no campo "Repositório" acima e salve.

🔗 Conecte seu GitHub
⚠️
Pré-requisito: Antes de continuar, conecte o GitHub no seu projeto Lovable.
Clique no botão ao lado de Publish no canto superior do Lovable.
O Bubbly precisa de um Token de Acesso Pessoal (PAT) do GitHub para ler e modificar o código do seu projeto.
Começa com ghp_ ou github_pat_ — gerado no GitHub Settings
📖 Como criar seu Token em 7 passos
  1. Abra github.com/settings/tokens
  2. Clique em "Generate new token" → "Generate new token (classic)"
  3. Em "Note", digite: Bubbly Extension
  4. Em "Expiration", escolha 90 days ou No expiration
  5. Em "Select scopes", marque ✅ TODAS as opções disponíveis (repo, workflow, write:packages, etc.) conforme a imagem abaixo
  6. Clique em "Generate token"
  7. 🔴 COPIE O TOKEN IMEDIATAMENTE! Ele só aparece uma vez
⚠️ Selecione TODAS as permissões no modo Classic para garantir que o Bubbly funcione corretamente.
✅ Detectado automaticamente Onde encontrar: O repositório será detectado automaticamente quando você abrir um projeto no Lovable. Ou copie da URL: github.com/joao/app → joao/app
